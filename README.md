# Immersive Writer

OmmWriter にインスパイアされた、Obsidian 用の没入ライティングモードプラグインです。
コマンドひとつで Obsidian が「静かな書斎」に変わります。

- ⌨️ **タイプ音** — 打鍵のたびに心地よい音が鳴る（4種類の音色）
- 🏔 **美しい背景** — フルスクリーン + UI 非表示 + シーン別のグラデーション背景と粒子演出
- 🎵 **幻想的な BGM** — 終わりのないアンビエントドローンをリアルタイム生成
- 📖 **読みやすい文字組み** — フォント・文字サイズ・行間・行長・タイプライタースクロール
- 🎛 **クイックパネル** — 没入モード中、画面右端にマウスを置くと現れるパネルで
  背景・BGM・打鍵音をその場で切り替え

すべての音と背景は **Web Audio / CSS / canvas でリアルタイム生成** されるため、
音源ファイルを一切含みません。画像も、フリーライセンスの満月写真を加工した
小さな月テクスチャ1枚（約40KB、`scripts/process_moon.py` で生成）を
埋め込んでいるだけです（配布サイズが小さく、著作権もクリーンです）。
ネットワーク通信も行いません。

## シーン

「背景 × BGM × 粒子」の組み合わせをワンタップで切り替えられます。

| シーン | 背景 | 粒子 | BGM |
|--------|------|------|-----|
| 雪原 | 淡青のグラデーション | 舞う雪（ときどき風に流される） | 明るく開けたパッド (D メジャー) |
| 月夜 | 夕暮れ→夜→夜明けへと時が流れる | またたく星・渡る月・たまの流れ星 | 静かな短調 (A マイナー) |
| オーロラ | 極北の夜空に緑のカーテンが揺れる | またたく星・たまの流れ星 | 明るく開けたパッド (D メジャー) |
| 森 | 深緑 | のぼる光の粒（蛍のように明滅） | 温かいメジャーセブンス (C) |
| セピア | ざらりとした紙の質感のセピア色 | なし | 最小限のドローン (F) |

月夜シーンでは、没入モードに入った瞬間が夕焼けの終わりで、そこから
実時間1分 = 作中10分の速さで夜が更けていきます。深夜を越え、月が沈み、
約75分の執筆で夜明けを迎えます（設定でオフにもできます）。

## タイプ音の音色

- **水滴** — 「ぴちょん」と澄んだ音（デフォルト）。ゆっくり打つと1打1滴、
  速く打つと数打ぶんの雫がたまってから「ぴちょん」と落ちます（ため中は
  極小の気配音が鳴り、満ちるほど音程が上がる）。Enter では大粒がまとまって
  落ち、滴の大きさ・跳ね方・水面の共鳴は毎回変わります
- **水滴2（母音）** — 母音キー（A/I/U/E/O）だけが滴を落とします。あ=大粒、い=小粒、
  お=いちばん低く丸い…と母音ごとに音が決まっていて、ローマ字入力では
  ことばのモーラのリズムで滴が落ちます。子音は沈黙。Enter は大粒、Space はやわらかい中粒
- **タイプライター** — カチャカチャという機械音。変換確定の Enter ではベルが鳴り、
  実際の改行では「ガチャッ」とキャリッジが戻ります
- **木琴** — キーボードの縦の列ごとに音程が決まるマレット音
  （z の列=ド、x の列=レ、c の列=ミ…と左から右へ上がり、鍵盤のように弾けます。
  Enter は低いド、Space はソ）

## インストール

コミュニティプラグインには未登録のため、手動でインストールします。

**方法1: git clone（おすすめ）**

このリポジトリは、ルートがそのまま Obsidian のプラグインフォルダになる標準構成です。
Vault の `.obsidian/plugins/` に直接クローンするだけで完了します。

```bash
cd <あなたのVault>/.obsidian/plugins
git clone https://github.com/hayato-watanabe/immersive-writer.git
```

以後の更新も `immersive-writer` フォルダ内で `git pull` するだけです。

**方法2: 手動コピー**

`main.js` / `manifest.json` / `styles.css` の3ファイルを
`<あなたのVault>/.obsidian/plugins/immersive-writer/` に置きます。

どちらの方法でも、最後に Obsidian を再読み込みし、
設定 → コミュニティプラグイン で **Immersive Writer** を有効化してください。

※ [BRAT](https://github.com/TfTHacker/obsidian42-brat) 経由の導入は、
GitHub Release（main.js / manifest.json / styles.css を添付）を作成すると可能になります。

## 使い方

- 左のリボンの **山と雪のアイコン** をクリック、またはコマンドパレットから
  **「没入モードを切り替え」** を実行すると没入モードに入ります
- Esc（フルスクリーン解除）でも没入モードから抜けられます
- 没入モード中は **画面右端の細いバーにマウスを重ねる** とクイックパネルが現れ、
  背景・BGM・打鍵音を書きながら切り替えられます。BGMと打鍵音は見出し横の
  スイッチでON/OFFでき、BGMは「シーン連動」のほかシーンと独立したムード
  （オーロラ／夜／森／凪）も選べます
- そのほかのコマンド:
  - **次のシーンへ切り替え** — 没入したままシーンを一巡できます
  - **BGM の再生/停止** — 没入モードと独立して BGM だけ流せます
  - **タイプ音のオン/オフ**
- ホットキー（例: `Cmd/Ctrl + Shift + Z`）を「没入モードを切り替え」に割り当てるのがおすすめです

## 設定

設定 → Immersive Writer から調整できます。

- **没入モード**: シーン / フルスクリーン / 周辺減光の強さ / パーティクル / 月夜の時間の流れ / タイプライタースクロール
- **タイプ音**: オン・オフ / 没入モード外でも鳴らすか / 音色 / 音量
- **BGM**: 没入モードで自動再生するか / 音量
- **文字と余白**: フォント（プリセット or 任意の font-family）/ 文字サイズ / 行の高さ / 本文の幅

## 開発

```bash
npm install
npm run dev    # ウォッチビルド
npm run build  # 型チェック + プロダクションビルド
```

設計の背景と実現可能性の調査は [docs/PLAN.md](docs/PLAN.md) を参照してください。

## 制限事項

- デスクトップ専用です（`isDesktopOnly: true`）。モバイル対応は今後の課題です
- OmmWriter のオリジナル音源・画像は使用していません。すべて本プラグインが生成するオリジナルです
