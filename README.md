# Calm Writer

OmmWriter にインスパイアされた、Obsidian 用の没入ライティングモードプラグインです。
コマンドひとつで Obsidian が「静かな書斎」に変わります。

- ⌨️ **タイプ音** — 打鍵のたびに心地よい音が鳴る（4種類の音色）
- 🏔 **美しい背景** — フルスクリーン + UI 非表示 + シーン別のグラデーション背景と粒子演出
- 🎵 **幻想的な BGM** — 終わりのないアンビエントドローンをリアルタイム生成
- 📖 **読みやすい文字組み** — フォント・文字サイズ・行間・行長・タイプライタースクロール
- 🎛 **クイックパネル** — 没入モード中、画面右端にマウスを置くと現れるパネルで
  背景・BGM・打鍵音をその場で切り替え

すべての音と背景は **Web Audio / CSS / canvas でリアルタイム生成** されるため、
音源ファイルや画像を一切含みません（配布サイズが小さく、著作権もクリーンです）。
ネットワーク通信も行いません。

## シーン

「背景 × BGM × 粒子」の組み合わせをワンタップで切り替えられます。

| シーン | 背景 | 粒子 | BGM |
|--------|------|------|-----|
| 雪原 | 淡青のグラデーション | 舞う雪 | 明るく開けたパッド (D メジャー) |
| 夜空 | 深い藍 | またたく星 | 静かな短調 (A マイナー) |
| 森 | 深緑 | のぼる光の粒 | 温かいメジャーセブンス (C) |
| 白い紙 | 温かな白 | なし | 最小限のドローン (F) |

## タイプ音の音色

- **水滴** — 「ぴちょん」と澄んだ音（デフォルト）
- **タイプライター** — カチャカチャという機械音。変換確定の Enter ではベルが鳴り、
  実際の改行では「ガチャッ」とキャリッジが戻ります
- **木琴** — ペンタトニック音階のやわらかいマレット音
- **ソフト** — こもった静かなタップ音。夜中の執筆向け

## インストール

コミュニティプラグインには未登録のため、手動でインストールします。

**方法1: git clone（おすすめ）**

このリポジトリは、ルートがそのまま Obsidian のプラグインフォルダになる標準構成です。
Vault の `.obsidian/plugins/` に直接クローンするだけで完了します。

```bash
cd <あなたのVault>/.obsidian/plugins
git clone https://github.com/hayato-watanabe/calm-writer.git
```

以後の更新も `calm-writer` フォルダ内で `git pull` するだけです。

**方法2: 手動コピー**

`main.js` / `manifest.json` / `styles.css` の3ファイルを
`<あなたのVault>/.obsidian/plugins/calm-writer/` に置きます。

どちらの方法でも、最後に Obsidian を再読み込みし、
設定 → コミュニティプラグイン で **Calm Writer** を有効化してください。

※ [BRAT](https://github.com/TfTHacker/obsidian42-brat) 経由の導入は、
GitHub Release（main.js / manifest.json / styles.css を添付）を作成すると可能になります。

## 使い方

- 左のリボンの **山と雪のアイコン** をクリック、またはコマンドパレットから
  **「没入モードを切り替え」** を実行すると没入モードに入ります
- Esc（フルスクリーン解除）でも没入モードから抜けられます
- 没入モード中は **画面右端の細いバーにマウスを重ねる** とクイックパネルが現れ、
  背景・BGM・打鍵音を書きながら切り替えられます。BGMは「シーン連動」のほか、
  シーンと独立したムード（オーロラ／夜／森／凪）やオフも選べます
- そのほかのコマンド:
  - **次のシーンへ切り替え** — 没入したままシーンを一巡できます
  - **BGM の再生/停止** — 没入モードと独立して BGM だけ流せます
  - **タイプ音のオン/オフ**
- ホットキー（例: `Cmd/Ctrl + Shift + Z`）を「没入モードを切り替え」に割り当てるのがおすすめです

## 設定

設定 → Calm Writer から調整できます。

- **没入モード**: シーン / フルスクリーン / 周辺減光の強さ / パーティクル / タイプライタースクロール
- **タイプ音**: オン・オフ / 没入モード外でも鳴らすか / 音色 / 音量
- **BGM**: 没入モードで自動再生するか / 音量
- **文字と余白**: フォント（プリセット or 任意の font-family）/ 文字サイズ / 行の高さ / 本文の幅

## 開発

```bash
npm install
npm run dev    # ウォッチビルド
npm run build  # 型チェック + プロダクションビルド
```

設計の背景と実現可能性の調査は [docs/PLAN.md](docs/PLAN.md) を参照してください。

## 制限事項

- デスクトップ専用です（`isDesktopOnly: true`）。モバイル対応は今後の課題です
- OmmWriter のオリジナル音源・画像は使用していません。すべて本プラグインが生成するオリジナルです
