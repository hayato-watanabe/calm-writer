# OmmWriter風 Obsidianプラグイン 実装プラン

OmmWriter（美しい背景・タイピング音・アンビエントBGMによる没入型ライティング環境）と同等の体験を、
Obsidianプラグインとして実装するための調査結果と実装計画。

---

## 1. 実現可能性の調査結果

結論: **主要4要素（タイピング音・背景画像・BGM・フォント）はすべて実現可能。**
Obsidianプラグインは Electron（デスクトップ）上で動く TypeScript/Web 技術なので、
Web Audio API・CSS・フルスクリーンAPIがそのまま使える。各要素には既存プラグインの実績がある。

### 1.1 タイピングごとの心地よい音 — ✅ 可能（実績あり）

- **実現方法**: エディタ（CodeMirror 6）の keydown イベントを `registerDomEvent` で捕捉し、
  **Web Audio API**（`AudioContext` + デコード済み `AudioBuffer`）で再生する。
- **レイテンシ**: Web Audio API なら数ms〜10ms程度で体感遅延なし。
  `HTMLAudioElement` は遅延・連打時の重複再生に難があるため**タイプ音には使わない**。
- **心地よさの作り込み**:
  - 通常キー / Enter / Space / Backspace で音を変える
  - 1キーごとに再生ピッチ・音量を微小ランダマイズ（機械的な連打感を消す）
  - 複数のサウンドスキーム（水滴系、ソフトタイプライター系、木琴系など）
- **先行事例**: [Click Clack](https://github.com/Acylation/obsidian-click-clack)、
  [Typewriter Sounds](https://github.com/adityaketkar/obsidian-typewriter-sounds) など。

### 1.2 美しくシンプルな背景画像 — ✅ 可能（実績あり）

- **実現方法**: 「没入モード」有効時に `document.body` へ CSS クラスを付与し、
  ワークスペース背景に画像/グラデーションを敷き、エディタ面を半透明カード状に浮かせる。
- **UIの排除**: リボン・サイドバー・タブバー・ステータスバーは CSS で非表示にできる
  （ProZen / Zen Mode / Ultra Zen Mode 等の Zen 系プラグインで確立された手法）。
- **フルスクリーン**: `requestFullscreen()` がデスクトップ版で動作する（ProZen が実証済み）。
- **演出**: ビネット（周辺減光）、ゆっくりした背景のケンバーンズ風アニメーション、
  canvas による雪・パーティクルなどのプロシージャル表現も可能。
  静的画像なしでも「幻想的な背景」は CSS + canvas だけで作れる（配布サイズ問題も回避できる）。

### 1.3 幻想的で没入感のあるBGM — ✅ 可能

- **実現方法**: ループ再生は `HTMLAudioElement`（BGMはレイテンシ不問）または Web Audio。
  シーン切替時のクロスフェード、タイプ音とは独立した音量調整を実装する。
- **代替案（アセット不要）**: Web Audio のオシレーター＋フィルターで
  アンビエントドローン（パッド音）を**プロシージャル生成**する方法もある。
  配布サイズがゼロになり、無限に続くBGMになる。M3で既成音源と比較検討する。

### 1.4 見やすいフォント — ✅ 可能（実績あり）

- **実現方法**: `@font-face`（base64埋め込み or プラグインフォルダのファイル参照）で
  フォントを読み込み、没入モード中のエディタに適用。行間・字間・行長（エディタ幅）・
  タイプライタースクロール（現在行を常に中央に保つ）も併せて調整する。
- **先行事例**: Custom Font Loader、Fontsource プラグインなど。
- **候補**: 日本語 = Noto Serif JP / しっぽり明朝、欧文 = EB Garamond（いずれも OFL ライセンス）。
  日本語フォントはファイルが大きい（数MB〜）ため、**サブセット化するか、
  デフォルトはシステムフォント指定（游明朝/ヒラギノ明朝）＋任意ダウンロード**とする。

## 2. 制約・できないこと

| # | 制約 | 影響と対策 |
|---|------|-----------|
| 1 | **コミュニティプラグインのインストールで配布されるのは `main.js` / `manifest.json` / `styles.css` の3ファイルのみ**。音・画像・フォントのバイナリは自動では配布されない | (a) 小容量アセット（タイプ音、計数百KB）は base64 で main.js に埋め込み、(b) 大容量（BGM・フォント・高解像度画像）は設定画面から GitHub Release を任意ダウンロード（Click Clack と同方式）。ネットワーク利用はストア審査で開示が必要 |
| 2 | **OmmWriter のオリジナル音源・画像・BGMは著作物であり流用不可** | CC0素材（freesound.org 等）・OFLフォント・自作/プロシージャル生成で「同等の体験」を再構築する。「クローン」ではなく敬意を払ったオマージュとして作る |
| 3 | **モバイル（iOS/Android）**: 音声自動再生の制限、ローカルファイル fetch の不具合、フルスクリーンAPI制限が既知 | 初期リリースはデスクトップ優先。`manifest.json` は当面 `isDesktopOnly: true` とし、モバイル対応は後続フェーズで graceful degradation を検討 |
| 4 | **アプリ全体のウィンドウを専用UIに置き換えることはできない**（OmmWriterは独立アプリだった） | ワークスペース上のCSSオーバーレイ＋フルスクリーンで実用上同等の没入感を実現。体感差はほぼない |
| 5 | **テーマ・他プラグインとのCSS競合** | 没入モード中は詳細度の高い自前CSSレイヤーで表示を強制。人気テーマ（Minimal 等）で動作確認する |
| 6 | **Obsidianウィンドウ外のキー入力は拾えない** | 問題なし（エディタ内のタイプ音だけ欲しいので、むしろ望ましい挙動） |

## 3. アーキテクチャ設計

```
omm-writer-mode/          (プラグインID案: 例 "calm-writer")
├── manifest.json
├── src/
│   ├── main.ts           プラグイン本体（ライフサイクル、コマンド登録）
│   ├── settings.ts       設定データ型 + 設定タブUI
│   ├── audio/
│   │   ├── engine.ts     AudioContext管理・AudioBufferキャッシュ
│   │   ├── keySounds.ts  keydown→音再生（キー種別マップ、ピッチ/音量ランダマイズ）
│   │   └── bgm.ts        BGMループ・クロスフェード・音量
│   ├── ambience/
│   │   ├── zenMode.ts    没入モードON/OFF（フルスクリーン、body class付与）
│   │   └── scenes.ts     シーン定義（背景・BGM・タイプ音のプリセットの組）
│   ├── assets/
│   │   ├── embedded.ts   base64埋め込みアセット（esbuildのバイナリローダーで生成）
│   │   └── download.ts   任意アセットのDL・plugin配下へのキャッシュ
│   └── styles.css        没入モードCSS（UI非表示、背景、フォント、ビネット）
├── esbuild.config.mjs    （.mp3/.woff2 を base64 で取り込むローダー設定）
└── docs/PLAN.md          本書
```

- **コマンド**: 「没入モードの切り替え」「BGM再生/停止」「タイプ音ミュート」＋リボンアイコン＋ホットキー
- **設定項目**: サウンドスキーム / タイプ音量 / BGM選択・音量 / シーン（背景）/ フォント / フルスクリーン連動 / タイプライタースクロール
- **シーン**という単位で「背景 × BGM × タイプ音」をワンタップで切り替えられるようにする（OmmWriterの体験の核）

## 4. マイルストーン

| フェーズ | 内容 | 完了条件 |
|---------|------|---------|
| **M1: 骨格＋タイプ音** | プラグイン雛形、esbuildビルド、Web Audioエンジン、埋め込み音源1スキーム、設定タブ（音量・ON/OFF） | Obsidianで打鍵ごとに遅延なく音が鳴る |
| **M2: 没入モード** | フルスクリーン、UI非表示、背景（グラデーション＋ビネット）、フォント適用、タイプライタースクロール | コマンド1つでOmmWriter的な画面に切り替わる |
| **M3: BGM** | ループ再生、クロスフェード、独立音量、（比較検討: プロシージャル生成版） | BGMを流しながら執筆できる |
| **M4: 磨き込み** | サウンドスキーム追加、シーン複数、canvas雪パーティクル、大容量アセットの任意DL、テーマ互換確認 | シーン切替で雰囲気が一変する |
| **M5: 公開準備（任意）** | README整備、ネットワーク利用の開示、コミュニティプラグイン申請 | ストア申請可能な状態 |

M1〜M2 が終わった時点で「使える」状態になるため、そこで一度フィードバックをもらうのが良い。

## 5. アセット調達方針

| 種類 | 方針 | サイズ |
|------|------|--------|
| タイプ音 | CC0素材（freesound等）を加工 or 自作。1スキーム = 4音 × 短尺 ≒ 50〜100KB | 埋め込み |
| BGM | CC0アンビエント（1〜2分ループ、OGG圧縮で1〜3MB）or Web Audioプロシージャル生成（0KB） | 任意DL or 生成 |
| 背景 | 第一候補: CSSグラデーション＋ノイズ＋canvasパーティクル（0KB）。第二候補: CC0写真 | 生成 or 任意DL |
| フォント | デフォルトはシステム明朝指定（0KB）。OFLフォントを任意DL | 任意DL |

## 6. リスクと未確定事項

- **打鍵音の「心地よさ」は音源の質に大きく依存する** — 技術より音選びが本体。複数候補を試せる設計にする。
- 日本語フォントのサブセット化は手間がかかるため、初期はシステムフォントで様子を見る。
- モバイル対応は需要を見てから判断（技術的ハードルが独立して高い）。
